### Improvements

- **Mobile hamburger menu** — Hamburger menu now works on all pages (home, blog, changelog, standalone pages). `MobileNavSheet` is rendered from the shared header so the toggle event is always handled.
- **Faster page transitions** — Removed Astro View Transitions (`ClientRouter`) from the base layout so link navigation uses normal browser behavior and feels faster.

### Changelog

- Changelog entries added for v8.0.0 and v8.2.0. The docs site now documents 8.x releases.
