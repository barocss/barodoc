툴팁은 **사용자가 트리거(감싼 요소)에 마우스를 올리거나 포커스할 때만** 추가 설명을 표시합니다. 툴팁 내용은 그 전에는 보이지 않으며, 본문에 고정된 텍스트처럼 두지 않습니다.

## 기본 사용법

<Tooltip client:load tip="Application Programming Interface - 프로그램이 서로 통신하는 방법">API</Tooltip> 위에 마우스를 올려 더 많은 정보를 확인하세요.

```mdx
<Tooltip client:load tip="Application Programming Interface">API</Tooltip> 위에 마우스를 올려 더 많은 정보를 확인하세요.
```

## 여러 툴팁

<Tooltip client:load tip="Static Site Generation - 빌드 시 페이지를 미리 렌더링">SSG</Tooltip>, <Tooltip client:load tip="Server-Side Rendering - 각 요청마다 페이지 생성">SSR</Tooltip>, <Tooltip client:load tip="Incremental Static Regeneration - 배포 후 정적 페이지 업데이트">ISR</Tooltip> 렌더링 전략에 대해 알아보세요.

```mdx
<Tooltip client:load tip="Static Site Generation">SSG</Tooltip>, 
<Tooltip client:load tip="Server-Side Rendering">SSR</Tooltip>, 
<Tooltip client:load tip="Incremental Static Regeneration">ISR</Tooltip>에 대해 알아보세요.
```

## Props

<ParamFieldGroup>
  <ParamField name="tip" type="string" required>
    툴팁 내용; 호버/포커스(사용자 액션) 시에만 표시됩니다.
  </ParamField>
  <ParamField name="children" type="ReactNode" required>
    트리거 요소(예: 용어); 사용자가 여기에 호버/포커스하면 툴팁이 보입니다.
  </ParamField>
  <ParamField name="client:load" type="directive" required>
    클라이언트 사이드 인터랙티브에 필요한 Astro 디렉티브
  </ParamField>
</ParamFieldGroup>
