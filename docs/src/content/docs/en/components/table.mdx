import { Table, TableHeader, TableBody, TableRow, TableCell, ParamField, ParamFieldGroup } from "@barodoc/theme-docs";

Use `Table`, `TableHeader`, `TableBody`, `TableRow`, and `TableCell` to build accessible, styled tables in docs.

## Basic usage

<Table>
  <TableHeader>
    <TableRow>
      <TableCell header>Feature</TableCell>
      <TableCell header>Status</TableCell>
    </TableRow>
  </TableHeader>
  <TableBody>
    <TableRow>
      <TableCell>i18n</TableCell>
      <TableCell>Supported</TableCell>
    </TableRow>
    <TableRow>
      <TableCell>RTL</TableCell>
      <TableCell>Supported</TableCell>
    </TableRow>
  </TableBody>
</Table>

```mdx
<Table>
  <TableHeader>
    <TableRow>
      <TableCell header>Feature</TableCell>
      <TableCell header>Status</TableCell>
    </TableRow>
  </TableHeader>
  <TableBody>
    <TableRow>
      <TableCell>i18n</TableCell>
      <TableCell>Supported</TableCell>
    </TableRow>
  </TableBody>
</Table>
```

## Cell alignment

Use the `align` prop on `TableCell` for left (default), center, or right alignment.

<Table>
  <TableHeader>
    <TableRow>
      <TableCell header>Name</TableCell>
      <TableCell header align="center">Count</TableCell>
      <TableCell header align="right">Value</TableCell>
    </TableRow>
  </TableHeader>
  <TableBody>
    <TableRow>
      <TableCell>Item A</TableCell>
      <TableCell align="center">1</TableCell>
      <TableCell align="right">$10</TableCell>
    </TableRow>
  </TableBody>
</Table>

<ParamFieldGroup>
