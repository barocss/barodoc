title: Card
description: Display content in cards

import { Card, CardGroup, ParamField, ParamFieldGroup } from "@barodoc/theme-docs";

Cards display related content or navigation links.

## Basic Card

<Card title="Getting Started" icon="🚀">
  Learn how to set up Barodoc for your project.
</Card>

```mdx
<Card title="Getting Started" icon="🚀">
  Learn how to set up Barodoc for your project.
</Card>
```

## Card with Link

<Card title="Documentation" icon="📚" href="/docs/introduction">
  Read the full documentation to learn more.
</Card>

```mdx
<Card title="Documentation" icon="📚" href="/docs/introduction">
  Read the full documentation.
</Card>
```

## Card Group

Group multiple cards in a responsive grid:

<CardGroup cols={2}>
  <Card title="Installation" icon="📦" href="/docs/guides/installation">
    Install Barodoc in your project.
  </Card>
  <Card title="Configuration" icon="⚙️" href="/docs/guides/configuration">
    Configure your documentation site.
  </Card>
  <Card title="Components" icon="🧩" href="/docs/components/callout">
    Explore available components.
  </Card>
  <Card title="Deployment" icon="🚀" href="/docs/guides/installation">
    Deploy to GitHub Pages.
  </Card>
</CardGroup>

```mdx
<CardGroup cols={2}>
  <Card title="Installation" icon="📦" href="/docs/guides/installation">
    Install Barodoc in your project.
  </Card>
  <Card title="Configuration" icon="⚙️" href="/docs/guides/configuration">
    Configure your documentation site.
  </Card>
</CardGroup>
```

## Props

### Card

<ParamFieldGroup>
  <ParamField name="title" type="string" required>
    Card title text
  </ParamField>
  <ParamField name="icon" type="string">
    Emoji icon displayed before the title
  </ParamField>
  <ParamField name="href" type="string">
    Link URL (makes the entire card clickable)
  </ParamField>
</ParamFieldGroup>

### CardGroup

<ParamFieldGroup>
  <ParamField name="cols" type="1 | 2 | 3 | 4" default="2">
    Number of columns in the grid layout
  </ParamField>
</ParamFieldGroup>
