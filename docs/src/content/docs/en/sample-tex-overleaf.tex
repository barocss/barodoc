\begin{abstract}
This sample uses full LaTeX packages (babel, geometry, amsmath, table, figure). It is rendered at \textbf{build time} with the LaTeX.js CLI, so you see the same result as in Overleaf. Run \texttt{pnpm build} or \texttt{pnpm dev} to generate the HTML.
\end{abstract}

\section{Introduction}

Overleaf compiles your document with a full TeX distribution. In Barodoc we achieve a similar result by pre-rendering \texttt{.tex} files at build time with the LaTeX.js CLI (Node), which supports packages and environments that the in-browser LaTeX.js viewer does not.

\section{Math}

With \texttt{amsmath} you can write:

\begin{equation}
  E = mc^2, \qquad
  \int_0^\infty e^{-x^2}\,dx = \frac{\sqrt{\pi}}{2}.
\end{equation}

Inline math: \(\sum_{n=1}^\infty \frac{1}{n^2} = \frac{\pi^2}{6}\).
